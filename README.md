# hi, i’m kai 👾

Artist, creative technologist, and yoga instructor.

I work across art, technology, embodiment, ecology, accessibility, privacy, and human–machine interaction.

I’ve been working on local-first AI systems, agent governance, memory and provenance, retrieval, cryptographic experiments, small interfaces, physical computing, and ways of making complex systems more understandable and recoverable.

I’m especially interested in what happens when software has to deal with uncertainty, consent, continuity, changing context, and actual human beings instead of idealized users.

I also work with somatics, yoga therapy, visual art, photography, electronics, Arduino / Raspberry Pi, LEDs, and whatever other medium makes sense for the question.

Most things start as an experiment and become either a tool, a protocol, a prototype, a diagram, or an unnecessarily large rabbit hole.
